# Source Serif 4

Unmodified variable webfonts from Adobe's official Source Serif release branch.

- Upstream: https://github.com/adobe-fonts/source-serif
- Pinned upstream commit: `80d3f8894c09c937bebfa9011247d2e1c79fd6f4`
- Version: 4.005
- License: SIL Open Font License 1.1; the original copyright and terms are in `LICENSE.md`.
- Roman source: `WOFF2/VAR/SourceSerif4Variable-Roman.ttf.woff2`
- Italic source: `WOFF2/VAR/SourceSerif4Variable-Italic.ttf.woff2`
- Weight range: 200-900. Optical sizing is available in both styles.

The files are served locally. No runtime font CDN or package dependency is required.

Use the same family for editorial display and reading text, with optical sizing enabled.
Navigation and controls retain the portfolio's existing sans-serif family.
